**Grounded facts verified before dispositions (per operating principles):**
1. `log_event` is internally guarded (`infolog.py:28-36`, "Infolog must never crash the pipeline";
   it catches its own exceptions and logs to stdlib DEBUG). A wrapper
   `try: log_event(f"...") except Exception: pass` is therefore **dead code** when the f-string
   args are already-validated locals -> `delete-dead`. Wrappers whose try-block also runs fallible
   COMPUTATION (`fits_binning_xy_from_header`, `np.mean` on odd arrays, SQL introspection,
   `float(x)` on possibly-None) are NOT dead -> `narrow+comment`.
2. Census line drift vs `9f3da34` was fixed in Part 0 (stable-ID line refresh); tranche-3 scope
   files matched exactly, so the line numbers below are current.
