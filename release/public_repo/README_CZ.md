# VYVAR

Automatizovana pipeline diferencialni fotometrie promennych hvezd: od surovych FITS
po kalibrovane, astrometricky vyresene a zmerene svetelne krivky s exportem pro AAVSO /
VarAstro a PDF reporty.

## Funkce

- Cely beh noci: import, kalibrace, align, platesolve, fotometrie
- Gaia DR3 cross-match, vyber srovnavacich hvezd, QC brany
- OSC vicekanalova extrakce a Johnson exporty
- Streamlit UI + headless pipeline (stejne vedecke cesty)
- Zkompilovane vedecke jadro v release; UI zustava interpretovane
